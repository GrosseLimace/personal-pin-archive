# Privacy Policy: personal-pin-archive

Operated by RavenRock. Last updated 2026-10-22.

personal-pin-archive is a single-user personal tool. It uses the Pinterest API, authorised by
its owner, to read the owner's own Pins and Boards and save copies of the images to the owner's
own storage.

- It collects no data from any other person.
- It has no user accounts, no analytics and no advertising.
- It shares no data with third parties.
- It does not publish, modify or delete anything on Pinterest.
- Access tokens are stored only on the owner's own machines.

To remove the app's access, revoke it in Pinterest's connected-apps settings.

Questions can be raised as an issue on this repository.

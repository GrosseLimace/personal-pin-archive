# personal-pin-archive

Operated by RavenRock.

A single-user, read-only personal tool. It uses the Pinterest API, authorised by its owner,
to read the owner's own Pins and Boards (including secret boards) and keep a private backup
of the saved images on the owner's own storage.

- Does not post, edit or delete anything on Pinterest.
- Does not access any other person's data.
- Is not distributed or offered to other users.

See [PRIVACY.md](PRIVACY.md) for the privacy policy.
